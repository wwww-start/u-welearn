# U校园 / WE Learn / 学习通 学习助手

浏览器扩展，支持 U校园、WE Learn 与 **学习通（超星）** 的页面识别、答案辅助填写、参考答案展示、连续翻页，以及学习通刷课与答题辅助。当前版本：**1.5.0**。

> 仅供学习交流，用于研究网页结构、浏览器扩展及 AI 辅助学习。请遵守平台规则与课程要求；不应用于代考、伪造学习记录或绕过访问限制。AI 输出需要自行核对，使用者对自己的操作负责。

## 安装与更新

1. 在 Edge 或 Chrome 的扩展管理页开启开发者模式。
2. 选择“加载解压缩的扩展”，选中包含 manifest.json 的项目根目录。
3. 更新已有安装时，在扩展管理页点击“重新加载”，再刷新课件页面。
4. 在设置中填写所使用服务的 API 地址、模型名称与自己的 API Key，并测试配置。

公开版移除了旧版内置的认证签名与解密常量。仅使用现有平台会话正常返回的可读答案和已显示的批改信息；接口拒绝或仅返回加密内容时转为 AI 辅助，不保证服务端答案可用。

API Key 保存在浏览器扩展设置中，请勿写入源码或提交到仓库。

## 本版修复

## 1.5.0 更新内容

### 学习通（超星）新增

- **刷视频**：`world:MAIN` 播放器守卫摘除 `ratechange/seeked/seeking` 事件监听，控制器负责倍速、跳尾、停滞恢复、播完自动切任务点。
- **跳过非视频任务点**：遇到 PPT、文档、图文任务自动跳过，只停在视频任务上。
- **刷课途中自动答题**：可选开关，遇到作业/测验任务点时顺手作答（不自动提交）。
- **章节练习适配**：支持旧版 `doHomeWorkNew` 结构——UEditor 富文本填空/简答、`li` 点击做单选/判断。
- **考试作答**：单题限时感知、分卷禁回跳、检测到人脸核验自动暂停。
- **模板系统**：新增 `templates/chaoxing.json`，站点题型模板页可见第三条。

### 模型与答案解析

- 新增 **DeepSeek V4.1 Flash** 内置预设（`https://api.deepseek.com` / `deepseek-flash`），已验证支持图片输入。
- 内置模型不再隐藏编辑按钮，可直接填写密钥。
- AI 答案解析改为四级降级：完整 JSON → 正则抠字段 → 字母串 → 原文，修复 JSON 被截断时把原文填进输入框的问题。
- 新增 LaTeX → 普通符号转换（`\pm\sqrt{70}/2` → `±√70/2`、`\frac{1}{2}` → `(1)/(2)`）。
- 单次请求加 `max_tokens: 2000`，避免长答案被截断。

### 交互调整

- 刷视频与答题按钮统一配色；移除独立的「考试作答」按钮（答题按钮已按页面类型自动路由）。
- 新增「刷课时自动答题」复选框，不勾选时只刷视频。
- 面板实时显示当前任务点类型（视频 / 文档 / PPT / 作业）与播放进度。

### 沿用 1.4.2 的修复

- 填空题每个空分别对应一个答案条目。同一空的不同拼写作为备选，不再挤占后续空位。
- 开放式简答支持将 AI 返回的多段文字合并到一个回答框；同页后续回答会参考已生成的示例。
- 排序、配对题可在运行日志中展示逐题参考答案并复制；显示来源，排列格式不完整时提示核对。
- 面板分别显示题组数、空位数、已填写数和已确认提交数。
- U校园覆盖阶段页签及练习页签，等待内容更新，并记录跳过和访问情况。
- WE Learn 限定当前课件与当前子页，先遍历内嵌子页，再进入外层目录下一项。
- 日志按纯文本显示，避免把答案中的 HTML 当作界面代码执行。

## 使用说明

“自动翻到下一页”从当前页面继续；需要完整遍历时请先打开课程第一个入口。“一键跳过”会记录未完成页面并继续，跳过项不计为完成。录音、自评、尚未适配的实际拖拽仍需用户处理。

网页返回的答案与 AI 参考答案会标明来源。答案获取受平台返回内容影响；音视频题缺少可读原文时会提示补充材料。开放式回答是示例，请结合自己的经历调整。提交确认不代表平台判定所有答案正确。

## 学习通（超星）支持

v1.5.0 新增，详见 [学习通指南.md](学习通指南.md)。

| 能力 | 说明 |
|---|---|
| 刷视频 | 双层机制：`world:MAIN` 的播放器事件守卫摘掉 `ratechange/seeked/seeking` 监听，再由控制器设倍速、跳尾、停滞恢复、自动切下一任务点 |
| 答题 | 作业 / 章节练习。三级取答案：页面已有答案 → 学习通内置 AI → 自带模型（支持多模态截图） |
| 考试 | 单题限时感知、分卷禁回跳、人脸核验自动暂停；**默认不自动交卷** |
| 章节练习 | 旧版 `doHomeWorkNew` 结构：UEditor 富文本填空白/简答，`li` 点击做单选/判断 |
| 答案核对 | 「核对未作答」列出漏题；「确认提交」二次确认后才交卷 |

### 关键实现点

- **播放器守卫**必须 `world: "MAIN"` + `document_start`，晚于播放器绑定即失效。
- **UEditor 填充**走浏览器原生 `execCommand('insertText')`，直接改 `innerHTML` 会绕过编辑器内部状态，提交时读不到。
- **跨 iframe 截图**需要逐层累加 `frameElement.getBoundingClientRect()` 偏移，并确认元素真正进入顶层视口后再截。
- **选项打乱**：部分页面 `.num_option` 的 `data` 属性是原始编号、文本才是显示编号，必须按显示编号匹配，否则会点错选项。
- **字体混淆**：题干与选项文字经自定义字体映射加密，DOM 文本形如 `寙寑寗线`，因此必须走截图视觉路径。

### 学习通不支持"直接从网页取答案"

实测结论：作答态页面的 HTML、全局变量、XHR 响应中均无标准答案字段（`doHomeWorkNew` 纯服务端渲染，无数据接口）。答案仅在**教师开放后的回顾页**（`.rightAnswerContent`）出现。这与 U校园（`/course/api/v3/answer/...` 直接下发）不同。

因此学习通作答以 AI 视觉识别为主，代码中仍保留"页面有答案则优先使用"的分支。

## 怎样使用

### API 配置
- 打开侧栏齿轮，填写服务商提供的 API Key、Base URL 与模型 ID；可使用兼容接口。
- 内置预设：**GLM-4-Flash**（`https://open.bigmodel.cn/api/paas/v4` / `glm-4-flash`）与 **DeepSeek V4.1 Flash**（`https://api.deepseek.com` / `deepseek-flash`）。
- DeepSeek V4.1 Flash 已验证支持图片输入，学习通的公式题会用整题截图走多模态识别。
- 点击“测试当前配置”确认连接后保存。401 表示认证失败，不要反复重试；429 应等待服务商限流恢复。
- Key 仅填在本机扩展设置中。调用 AI 时，相关题目、选项及可读材料会发送至你配置的服务商；不要填写敏感个人信息。

### U校园与 WE Learn
1. 在浏览器正常登录平台，打开具体课件题目页，而不是课程列表。
2. 打开扩展侧栏，检查模型配置；需完整遍历时从课程第一个入口开始。
3. 点击“自动答题”。“自动翻到下一页”控制连续处理；“一键跳过”开启时记录未完成页面并尝试继续。
4. 查看日志中的答案来源、跳过原因和提交状态。已填写不等于已提交，已提交不等于全对。
5. 排序、配对等需要手工操作的页面，查看日志中的逐题参考答案并复制，再手动完成。
6. 更新后在浏览器扩展管理页重新加载扩展，并刷新已经打开的课件页。

## 暂未实现与已知限制

| 情况 | 当前行为 / 需要你做什么 |
|---|---|
| 实际拖拽排序、图片连线配对 | 可解析时显示参考答案；真实拖拽写入尚未全面适配，需手动操作 |
| 只有图片、无可读文字的选项 | 尚无通用视觉理解流程，可能提示材料不足 |
| 听力、视频没有可读字幕或原文 | 不保证作答；本版不自带可靠的通用云端转写，需补充材料 |
| 录音、口语、自评、讨论发布 | 需要人工参与；Discussion 1/2/3 类讨论页按跳过策略处理 |
| 开放式简答 | AI 生成的是示例，不代表你的真实经历，请自行修改 |
| 服务端答案接口拒绝访问或仅返回加密数据 | 转为 AI 辅助，不使用硬编码签名/解密常量绕过限制 |
| 未识别页面、加载失败、控件写入失败 | 记录原因；按“一键跳过”设置继续或停留，跳过不计为完成 |
| 登录过期、API 401、限流 | 停止或等待处理，不通过反复请求规避限制 |
| 连续翻页 | 从当前位置向后处理；离线回放通过不等于全部线上课程均无漏页 |
| 自动提交 | 仅支持已适配的提交与确认流程；没有成功证据时不计为已确认提交 |
| 学习时长 | 不承诺修改平台计时或达到课程完成条件；以真实学习及平台记录为准 |

公开源码不包含账号密码、API Key、浏览器会话或课程采集内容。请勿把这些内容提交到 Issues 或仓库。
